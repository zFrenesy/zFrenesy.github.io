# Contributing to we-solve

Every problem page on {{SITE_URL}} has a **Contribute** section with links prepared for that problem. There are four ways in:

1. **No setup:** fill in the [submission form](https://github.com/{{RESEARCH_REPO}}/issues/new/choose). Paste your write-up or attach a PDF; `.tex` files must be pasted or zipped.
2. **Chat assistant:** copy the research prompt from the problem page into ChatGPT, Claude, Gemini or another assistant, then paste the result into the form.
3. **Coding agent:** open this repository in Codespaces, Codex or Claude Code and ask the agent to follow [AGENTS.md](AGENTS.md). It opens the pull request from your own account.
4. **Git:** fork, run `rp new attempt <HANDLE>`, `rp check` and `rp submit`. See [AGENTS.md](AGENTS.md) for the full workflow and formats.

Before you submit:

- **Credit people and tools.** Name every human contributor and every model, with versions or "unknown".
- **Cite your sources.** Only references you have checked.
- **Respect licences.** New work is published under CC BY 4.0 (software under Apache-2.0).
- **Respect third-party rights.** Do not paste material you may not share.
- **Everything is public immediately.** Issues and pull requests are visible as soon as you open them.

Automated format checks run on every pull request. Submissions then wait in the queue for screening and publication; nothing is merged by hand. A passing check, or publication, does not establish that a result is correct or new.
