✨ What Is vellum.nvim?

If you write in Markdown (a simple way to format text), you know the struggle of trying to imagine what your document will look like when it's finished. vellum.nvim eliminates that guesswork completely.

Imagine typing a line like # Welcome to my notes and instantly seeing it transform into a big, beautiful heading right next to your code. That's exactly what vellum.nvim does.

It works directly inside Neovim, a popular programming editor. A small panel opens beside your text, showing a real-time, pixel-perfect preview of your Markdown file, just like it would appear on GitHub.

🚀 Key Features That Make You Smile

👁️ Live, Instant Preview

Every keystroke you make appears in the preview immediately. No waiting, no saving and reloading — just pure, real-time magic.

📊 Mermaid Diagrams, Real Images

Have you ever written a flowchart or a sequence diagram in Markdown? vellum.nvim converts those Mermaid codes into actual, viewable images right in your terminal. No more mental gymnastics!

The preview isn't just functional — it's gorgeous. Colors, fonts, spacing, and styles are all carefully matched to GitHub's markdown look, so you know exactly what your readers will see.

You don't need to be a tech wizard to get vellum.nvim up and running. Follow these simple steps:

  1. Step 1: Click the green "Download" button above. It will take you to the vellum.nvim page on GitHub.
  2. Step 2: Once you're on the page, look for the "Releases" section or the "Download ZIP" button. Click it to download the file to your computer.
  3. Step 3: Find the downloaded file in your "Downloads" folder. If it's a ZIP file (a compressed folder), right-click on it and select "Extract All". This will open the folder with all the necessary files.
  4. Step 4: Inside the extracted folder, you'll find instructions specific to your setup. Typically, you'll copy this folder into your Neovim configuration directory (for advanced users) — but if that sounds scary, don't worry! The main README file inside the folder explains everything in plain language.
